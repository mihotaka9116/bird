Mon poème (モン・ポエム)
印象に残った言葉たちが、泡のように浮かぶ場所。

繊細なタイポグラフィと、水底から浮かび上がる泡のようなアニメーションを組み合わせた、言葉を慈しむためのポートフォリオサイトです。

📋 Concept
「Mon poème（私の詩）」というタイトルの通り、読書や映画、日々の生活の中で心に留まった言葉たちを、静かな空間にストックしていくことを目的としています。
デザインは**「静寂」「透明感」「言葉の重み」**をテーマにしており、ユーザーがカードをクリックすることで初めて言葉が姿を現す「対話型」の演出を取り入れています。

✨ Features
Bubble Animation: JavaScript を使用し、ランダムな大きさ・速度で下から上へと昇っていく泡を生成。

Feather Hover Effect: 各セクションのタイトルにマウスを乗せると、羽（feather）のアイコンがふわふわと浮遊する遊び心をプラス。

Accordion Cards: 最小限の情報（著者名）から、クリックすることで深い言葉（引用文）が開閉するアニメーション。

Glassmorphism: ヘッダーやカードに backdrop-filter を使用し、背景のグラデーションを活かした透明感のある質感を実現。

Responsive Design: ハンバーガーメニューの実装により、スマートフォン・タブレットでも美しく閲覧可能。

🛠 Tech Stack
